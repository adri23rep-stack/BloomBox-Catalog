# BloomBox news images

Place news images and animated GIFs in this directory. Reference them using `https://raw.githubusercontent.com/adri23rep-stack/BloomBox-Catalog/main/news/images/<filename>` in the `media` field of `news/es.json` and `news/en.json`.

Recommended name for the requested Kirby GIF: `kirby-parasol.gif` (pending binary upload).
