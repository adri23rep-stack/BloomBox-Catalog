# BloomBox Themes Catalog

The theme store reads `catalog/themes.json` on `main`. Only approved community designs go here.

## Theme entry

```json
{
  "version": 1,
  "themes": [
    {
      "id": "example-theme",
      "name": "Example Theme",
      "author": "Creator",
      "description": "A short description.",
      "downloadURL": "https://raw.githubusercontent.com/adri23rep-stack/BloomBox-Catalog/main/themes/example-theme.bbtheme",
      "previewURL": null
    }
  ]
}
```

The sample is documentation only; **do not add it to the live index**.

- Each download must be a reviewed `.bbtheme` v2 file under `themes/`, within the app's 90 MB import limit.
- Do not include IPAs, executables, tweaks, pairing data, credentials, account tokens, or private app backups.
- Ask creators for permission before publishing their wallpapers, GIFs, and other media.
- Users may import local `.bbtheme` files without submitting their themes publicly.
- Merge the catalog index only after Theme Store testing.
